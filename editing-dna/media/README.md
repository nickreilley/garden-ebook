# Media (local only)

Everything in this folder except this README is ignored by git, so videos stay on your Mac and never get pushed. Export at full quality, since there's no size limit here.

| Folder | What goes in it |
|---|---|
| `raw/` | Unedited clips, used for calibration (for example, a 10–20 second talking-head clip) |
| `mine/` | Your finished edits, plus their Resolve timeline exports (File → Export → Timeline → FCPXML) |
| `refs/` | Screen recordings of other creators' graphics you love (Cmd + Shift + 5) |
| `renders/` | Claude's output: calibration options and tests |

Your *explanations*, such as why a reference works or what's wrong with an option, go in `../sources/` as text, so they're saved to GitHub.
